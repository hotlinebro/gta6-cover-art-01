# Vice Cover Studio — GTA 6-style cover art maker

[![gta6-cover-art-01](https://make.fun/badge/gta6-cover-art-01.svg)](https://make.fun/bounty/gta6-cover-art-01)
[![rank](https://make.fun/badge/gta6-cover-art-01/hotlinebro/gta6-cover-art-01/rank.svg)](https://make.fun/bounty/gta6-cover-art-01)
[![reward](https://make.fun/badge/gta6-cover-art-01/hotlinebro/gta6-cover-art-01/reward.svg)](https://make.fun/bounty/gta6-cover-art-01)

An offline web app that turns your own photos and a caption into GTA 6-style cover art: multi-panel poster layout, bold caption lettering, Vice City sunset and neon colour grades, exported as PNG in 1080x1080, 1080x1350 and 1920x1080.

Entry for the make.fun bounty [Make GTA 6 Cover Art](https://make.fun/bounty/gta6-cover-art-01). All artwork, lettering and fonts are original or openly licensed — no Rockstar Games logo, artwork or fonts.
